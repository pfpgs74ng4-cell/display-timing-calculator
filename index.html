Display Timing Calculator

Flexible timing parser + PCLK / CSI / DSI / DP calculations + Weston modeline + Markdown report export.
Input Timing
Flexible parser: order does not matter. Plain text and Markdown tables are both accepted. Common aliases include:
HActive / HACT / H_ACTIVE / HorizontalActive / HDisplay / HDISP
HTotal / H_TOTAL / HorizontalTotal
HSW / HSyncWidth / HSWIDTH / HSyncPulseWidth
HFP / HFrontPorch / HorizontalFrontPorch
HBP / HBackPorch / HorizontalBackPorch
and the equivalent V* names, plus FPS / FrameRate / RefreshRate.
The parser ignores comments after #, //, or ;. Separators such as =, :, or whitespace are accepted. Markdown rows such as | HActive | 1920 | are also supported.
